# Research Mastermind — контекст сообщества

## Что это

Закрытое сообщество ~106 человек, объединённых практическим интересом к AI.
Три столпа: ресёрч (исследования), синхронизация (видеозвонки), нетворк (обмен опытом).
Основал Артём Субботин (@silikonniy_meshok). Канал живого общения + архив материалов.

## Формат встреч

- **Research Mastermind** — видеозвонки по средам
- 3 спикера за встречу, ~30 минут каждый (15 мин доклад + 15 мин Q&A)
- Утренний слот 10:00 МСК или вечерний 19:00 МСК (чередуются)
- Платформа: Google Meet, запись на YouTube
- Регистрация слушателей: Luma, спикеров: Google Form

## Аудитория

Смешанная: от разработчиков и продуктологов до гуманитариев, архитекторов, филологов.
Общий знаменатель — интерес к AI и желание применять его в своей работе.
Уровень от новичков до серьёзных специалистов с продуктами.

## Тематики выступлений (реальные примеры)

- AI-консалтинг и структура рынка
- Мультиагентные системы для SEO
- Патентные исследования с AI
- Голосовые AI-агенты (Voice AI)
- Нейрофотография
- Медицинский AI-помощник на OpenClaw
- Изучение языков с помощью ИИ
- ИИ в творчестве и литературном редактировании
- Vibe Coding и agent-first документация
- Финансовое моделирование с AI
- СДВГ и продуктивность с AI
- Корпоративные A2A-системы

## Главная проблема: барьер выступления

Люди не заявляются спикерами. Причины:
1. **Высокая планка** — первые спикеры задали серьёзный уровень, остальные боятся не дотянуть
2. **Синдром самозванца** — "я не технарь", "мне нечего рассказать", "это стыдненько"
3. **Путаница формата** — участники думают, что нужен серьёзный академический доклад, а не неформальный рассказ
4. **Пассивность** — ~2/3 участников — "пассажиры"

Именно для решения этой проблемы создан данный набор скиллов.

## Тон общения

- Русский с обильными англицизмами из IT (ресёрч, пайплайн, вайб, deep dive)
- Неформальный, на "ты"
- Юмор, мемы, самоирония
- Взаимопомощь и обмен инструментами

## Форматы презентаций (из анализа реальных)

### По типу файла:
- PPTX (PowerPoint/Google Slides) — для визуальных, структурированных докладов
- PDF из Figma/Canva — для дизайнерских презентаций
- PDF из Slides — для минималистичных текстовых
- Дополнительные материалы: MD-шаблоны, XLSX-модели, ссылки на GitHub

### По объёму (10-32 слайда, зависит от глубины):
- Короткий pitch (10-12 слайдов) — для продуктовых презентаций, MVP, идей
- Средний кейс (12-18 слайдов) — для разбора проекта с демо
- Развёрнутый мастер-класс (20-32 слайда) — для обучающих тем с промптами/инструкциями

### Типичная структура (паттерн из 7 реальных презентаций):
1. Титульный слайд (тема + автор + дата)
2. О спикере (регалии, опыт, контакты — 1 слайд)
3. Проблема / контекст рынка (1-2 слайда)
4. Решение / подход / продукт (основной блок)
5. Демо / скриншоты / архитектура (2-5 слайдов)
6. Результаты / метрики (1-2 слайда)
7. Итоги + CTA + контакты (1-2 слайда)

### Два стиля подачи:
- **Методичка** — модульная, каждый слайд = отдельный приём/промпт, "бери и делай"
- **Нарратив** — история, кейс, рефлексия, с культурологическими отсылками

### Элементы хороших презентаций:
- QR-код на финальном слайде (на продукт или Telegram-канал)
- Конкретные промпты, которые можно скопировать
- Скриншоты работающего продукта
- Сравнительные таблицы (мы vs конкуренты)
- Чёткие метрики результатов ("50 статей/месяц", "2500+ посетителей с нуля")
