# Masterminder

Набор из 9 скиллов для [Claude Code](https://docs.anthropic.com/en/docs/claude-code/overview), который за 30 минут разговора превращает «у меня есть проект, но рассказывать не о чем» в готовое выступление с презентацией и шпаргалкой спикера.

## Зачем это нужно

Masterminder создавался для Research Mastermind — закрытого AI-сообщества, где больше ста человек делятся опытом применения AI в своих проектах. Каждую неделю три спикера выступают с короткими докладами. Но слоты часто пустуют — не потому что нечего показать, а потому что людям кажется, что их проект «слишком простой», «у других интереснее», «кому это вообще нужно».

Masterminder решает именно эту проблему. Он не делает красивые слайды — для этого есть Gamma и Beautiful.ai. Он делает то, чего не умеет ни один генератор презентаций: **вытягивает из автора суть проекта, находит угол, через который этот проект действительно интересно слушать, и собирает всё в готовое выступление**. Автору остаётся только записаться в спикеры.

## Как это работает

Один запуск. Одна команда. AI сам ведёт через весь процесс:

```
"У меня есть проект..."
         │
         ▼
  ┌──────────────┐   30+ вопросов с кликабельными вариантами ответов.
  │  Interview   │   3 волны: охват → расширение → глубина.
  └──────┬───────┘   AI изучает проект заранее и предлагает гипотезы.
         │
         ▼
  ┌──────────────┐   Находит, ПОЧЕМУ проект интересно слушать.
  │    Angle     │   Подбирает нарратив (SCQA, Before/After, Hero's Journey...).
  └──────┬───────┘   Согласует с автором.
         │
         ▼
  ┌──────────────┐   Структура слайдов, тезисы, подготовка к Q&A,
  │   Concept    │   прогноз вопросов из зала с готовыми ответами.
  └──────┬───────┘
         │
         ▼
  ┌──────────────┐   Текст на каждом слайде + speaker notes (7-12 предложений),
  │    Slides    │   написанные так, что их можно просто прочитать вслух.
  └──────┬───────┘
         │
         ▼
  ┌──────────────┐   Готовая PPTX-презентация.
  │     PPTX     │   Два движка: Gamma (AI-дизайн) или python-pptx (локально).
  └──────┬───────┘
         │
         ▼
  ┌──────────────┐   Одностраничный план: тайминг, опорные точки,
  │  Cheatsheet  │   козыри для Q&A. Распечатал — и на сцену.
  └──────────────┘
```

**На выходе:** концепция, контент слайдов, PPTX-презентация, шпаргалка спикера.

## 9 скиллов

| Скилл | Что делает |
|---|---|
| `mastermind` | Оркестратор. Единая точка входа — запускает все остальные скиллы в правильном порядке |
| `mastermind-interview` | Многоволновое интервью. 30+ вопросов с кнопками, адаптируется под ответы |
| `mastermind-angle` | Поиск угла подачи. Превращает "я сделал штуку" в "историю, которую хочется слушать" |
| `mastermind-concept` | Структура выступления. Слайды, тезисы, Q&A-подготовка |
| `mastermind-slides` | Контент слайдов. Текст + speaker notes для каждого слайда |
| `mastermind-voice` | Стилевой движок. Убирает AI-слоп, адаптирует тон под мероприятие |
| `mastermind-pptx` | Генерация PPTX. Gamma (AI-дизайн) или html-deck (HTML-first с vision-loop) + постобработка |
| `mastermind-deck` | HTML-first движок: DTCG-токены → Tailwind/CSS → Playwright → vision-loop → PPTX. 3 sub-skills (tokens, layout, visionloop) |
| `mastermind-cheatsheet` | Шпаргалка спикера. Одна страница на всё выступление |

## Установка

Открой Claude Code и отправь ссылку на этот репозиторий:

```
Установи скилл из https://github.com/svetozarov/mastermind-skills
```

Claude сам клонирует репозиторий, скопирует скиллы в нужную папку и установит зависимости.

### Ручная установка

<details>
<summary>Если предпочитаешь установить вручную</summary>

#### 1. Клонируй и скопируй скиллы

**macOS / Linux:**
```bash
git clone https://github.com/svetozarov/mastermind-skills.git
cp -r mastermind-skills/mastermind* ~/.claude/skills/
```

**Windows (CMD):**
```cmd
git clone https://github.com/svetozarov/mastermind-skills.git
xcopy /E /I mastermind-skills\mastermind* %USERPROFILE%\.claude\skills\
```

#### 2. Установи зависимости Python

```bash
pip install python-pptx comtypes fonttools
```

- `python-pptx` — генерация и редактирование PPTX
- `comtypes` — встраивание шрифтов через PowerPoint COM (Windows)
- `fonttools` — анализ шрифтовых файлов

#### 3. (Рекомендуется) Настрой Gamma для AI-дизайна слайдов

[Gamma](https://gamma.app) генерирует визуально качественные презентации. Для интеграции:

1. В Claude Code: Settings → MCP Servers → добавь Gamma
2. (Опционально) Gamma Pro ($18/мес) — автоскачивание PPTX через API

</details>

### Профиль мероприятия

По умолчанию скилл настроен на Research Mastermind (закрытое AI-сообщество). Для своего мероприятия скилл спросит о нём при первом запуске и создаст `event-profile.md`.

## Использование

Открой Claude Code и скажи:

```
/mastermind
```

Или просто: *"Хочу выступить с этим проектом на митапе"*

Дальше AI сам проведёт через весь процесс. Тебе нужно только отвечать на вопросы — большинство с готовыми вариантами ответов, просто жми кнопку.

### Что создаётся

Скилл создаёт папку `Masterminder/` в текущей рабочей директории Claude Code:

```
[cwd]/Masterminder/
├── projects/
│   └── [название-проекта]/
│       ├── концепция.md            — структура + Q&A
│       ├── слайды.md               — контент каждого слайда
│       ├── шпаргалка-спикера.md    — план на одну страницу
│       ├── [Название]-*.pptx       — готовая презентация
│       └── _work/                  — промежуточные артефакты
└── _temp/                          — временные файлы
```

## Что нужно для запуска

- [Claude Code](https://docs.anthropic.com/en/docs/claude-code/overview) (подписка Anthropic)
- Python 3.12+
- `python-pptx`, `comtypes`, `fonttools` (pip install)
