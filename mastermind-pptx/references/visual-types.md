# Visual Types — каталог типов слайдов

Все координаты берутся из `design-system.json` → `slide_layouts`.
Каждый тип = точное описание элементов с позициями, шрифтами и лимитами контента.

---

## Decision Framework

Для каждого слайда задай вопрос: "Что за контент?"

| Контент | Visual Type |
|---------|-------------|
| Открытие / заголовок выступления | `cover` |
| Разделитель между разделами | `section_divider` |
| Оглавление / план | `agenda` |
| 3-6 буллетов | `bullets` |
| Текст + изображение/медиа | `content_text_media` |
| График / диаграмма / данные | `data_chart` |
| Цитата | `quote` |
| Команда / авторы | `team` |
| Хронология / этапы во времени | `timeline` |
| Сравнение двух вещей | `comparison` |
| Финал / контакты / призыв к действию | `closing` |
| Список пунктов (без медиа) | `bullets` |
| Одно крупное число/факт | `big_number` |
| 3-4 параллельных блока | `cards` |
| Последовательность шагов | `process` |

---

## Правила разнообразия

В презентации из 10-15 слайдов:
- **Максимум 3 слайда** одного visual type
- **Минимум 4 разных** visual types
- **Не ставить** два одинаковых типа подряд
- **Чередовать** плотные и "воздушные" слайды

## Базовые 10 типов

### 1. cover — Титульный слайд

**Layout шаблона:** TITLE_1 (CENTER_TITLE + SUBTITLE) или BLANK
**Whitespace target:** 75%

| Элемент | left | top | width | height | font_pt | bold |
|---------|------|-----|-------|--------|---------|------|
| title | 0.75 | 1.5 | 11.83 | 1.75 | 48 | Да |
| subtitle | 0.75 | 3.5 | 11.83 | 0.75 | 28 | Нет |
| metadata | 0.75 | 5.0 | 6.0 | 0.9 | 18 | Нет |
| logo | 0.5 | 0.4 | 1.5 | 0.8 | — | — |

**Лимиты:** title ≤14 слов, subtitle = 1 строка
**Пример:**
```python
title_box = slide.shapes.add_textbox(Inches(0.75), Inches(1.5), Inches(11.83), Inches(1.75))
tf = title_box.text_frame
tf.text = slide_data['title']
tf.paragraphs[0].font.size = Pt(DS['slide_layouts']['cover']['title']['font_pt'])
tf.paragraphs[0].font.bold = True
```

### 3. agenda — Оглавление / план

**Layout шаблона:** TITLE_AND_BODY
**Whitespace target:** 55%

| Элемент | left | top | width | height | font_pt | bold |
|---------|------|-----|-------|--------|---------|------|

### 4. content_text_media — Текст + медиа

**Layout шаблона:** TITLE_AND_TWO_COLUMNS или TITLE_ONLY + ручная вёрстка
**Whitespace target:** 55%

| Элемент | left | top | width | height | font_pt | bold |
|---------|------|-----|-------|--------|---------|------|
| action_title | 0.5 | 0.3 | 12.33 | 0.75 | 26 | Да |
| text_area | 0.5 | 1.3 | 5.92 | 5.5 | 20 | Нет |
| media_area | 6.67 | 1.3 | 6.17 | 5.5 | — | — |
| footnote | 0.5 | 7.0 | 12.33 | 0.35 | 11 | Нет |

**Лимиты:** ≤75 слов в text_area, ≤6 буллетов
**Варианты split:**
- 50/50: text_width=5.92, media_left=6.67, media_width=6.17
- 60/40: text_width=7.3, media_left=8.0, media_width=5.0
- 40/60: text_width=4.8, media_left=5.5, media_width=7.3

### 7. team — Команда / авторы

**Layout шаблона:** TITLE_ONLY или BLANK

| Элемент | left | top | width | height | font_pt | bold |
|---------|------|-----|-------|--------|---------|------|
| title | 0.5 | 0.3 | 12.33 | 0.7 | 28 | Да |

**Grid по количеству:**
| N | Сетка | Фото | card_width |
|---|-------|------|-----------|
| 2-3 | 1×N | 1.5-2.0" | 3.5 |
| 4 | 1×4 или 2×2 | 1.5" | 2.8 |
| 5-6 | 2×3 | 1.2-1.5" | 3.5 |
| 7-8 | 2×4 | 1.0-1.2" | 2.8 |

**Формула gap:** `(slide_width - 2*margin - N*card_width) / (N-1)`
**Лимиты:** ≤8 человек на слайд, оптимум 4

### 8. timeline — Хронология

**Layout шаблона:** TITLE_ONLY или BLANK

| Элемент | left | top | width | height | weight_pt |
|---------|------|-----|-------|--------|-----------|
| title | 0.5 | 0.3 | 12.33 | 0.7 | — |
| line | 1.0 | 3.5 | 11.33 | — | 2.5pt |

**Формулы:**
- node_spacing = available_width / (N - 1)
- нечётные события: выше линии (y=1.5-3.0)
- чётные события: ниже линии (y=4.0-5.5)
- node_diameter = 0.4"

**Лимиты:** ≤8 событий, оптимум 5, label ≤5 слов, desc ≤20 слов

### 12. big_number — Крупное число / факт

**Layout шаблона:** BIG_NUMBER или BLANK

| Элемент | left | top | width | height | font_pt | bold |
|---------|------|-----|-------|--------|---------|------|
| action_title | 0.5 | 0.3 | 12.33 | 0.75 | 26 | Да |

| label | 1.5 | 4.7 | 10.33 | 0.8 | 28 | Нет |
| context | 1.5 | 5.7 | 10.33 | 0.6 | 18 | Нет |

**Лимиты:** number ≤6 символов (включая %), label ≤6 слов

### 13. cards — Параллельные блоки

**Layout шаблона:** TITLE_ONLY или BLANK

| Элемент | left | top | width | height | font_pt | bold |
|---------|------|-----|-------|--------|---------|------|
| action_title | 0.5 | 0.3 | 12.33 | 0.75 | 26 | Да |
| cards_zone | 0.5 | 1.3 | 12.33 | 5.5 | — | — |

**Формулы:**
- 3 карточки: card_width = (12.33 - 2×0.25) / 3 ≈ 3.94"
- 4 карточки: card_width = (12.33 - 3×0.2) / 4 ≈ 2.93"

**Лимиты:** ≤4 карточки, ≤20 слов/карточка, title ≤5 слов
**Структура карточки:** иконка/число (опц.) + заголовок bold + текст body

### 14. process — Последовательность шагов

**Layout шаблона:** TITLE_ONLY или BLANK

| Элемент | left | top | width | height | font_pt | bold |
|---------|------|-----|-------|--------|---------|------|
| action_title | 0.5 | 0.3 | 12.33 | 0.75 | 26 | Да |
| steps_zone | 0.5 | 1.3 | 12.33 | 5.5 | — | — |

**Формулы:**
- step_width = available_width / N
- arrow_between = 0.15"

**Лимиты:** ≤6 шагов, оптимум 4, ≤12 слов/шаг, step_title ≤4 слова
**Структура шага:** номер (крупно, accent) → заголовок (bold) → описание (body)

## Правила контента (общие)

| Параметр | Лимит |
|----------|-------|
| Буллетов на слайде | max 6 |
| Слов на буллет | max 8 |
| Общее кол-во слов body | max 40 |
| Уровней вложенности | max 2 |
| Один слайд = | одно сообщение |
| Min размер шрифта (проекция) | 18pt |
| Glance test | 3 секунды |

**Если контент не помещается — разбей на 2 слайда. Никогда не уменьшай шрифт.**
