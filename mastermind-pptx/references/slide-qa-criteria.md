# Slide QA Criteria — Vision Evaluation Checklist

Используется при проверке каждого слайда через Read (PNG).
Каждый критерий выдаёт: **PASS / WARN / FAIL** + описание проблемы.

---

## Обязательные проверки (Critical — FAIL блокирует слайд)

### C1. Safe Zone
Весь текст и смысловые элементы должны находиться внутри безопасной зоны шаблона.
- Для Modern Business: контент начинается не раньше **left ≈ 3.9"** (после декоративной волны)
- **FAIL**: любой текст/элемент перекрыт декоративным фоном шаблона
- **PASS**: все элементы читаются без перекрытия

### C2. Text Readability
Весь текст на слайде должен быть читаем.
- **FAIL**: текст обрезан, наложен на другой элемент, выходит за границы shape
- **FAIL**: цвет текста сливается с фоном (contrast ratio < 4.5:1 визуально)
- **PASS**: весь текст виден, иерархия чёткая

### C3. Content Visibility
Ни один смысловой элемент (заголовок, буллет, число, таблица, карточка) не должен быть скрыт или обрезан.
- **FAIL**: элемент уходит за край слайда
- **FAIL**: элемент полностью перекрыт другим элементом

---

## Важные проверки (Major — WARN требует исправления)

### M1. Vertical Balance
Контент должен занимать **50–85%** доступной высоты слайда.
- **WARN**: нижние 40%+ слайда полностью пусты при наличии контента только наверху
- **WARN**: контент переполняет слайд и сжимается до нечитаемости
- **PASS**: контент равномерно занимает доступную область

### M2. Horizontal Use of Space
Контент должен использовать доступную ширину (правее волны) без чрезмерных пробелов.
- **WARN**: весь контент зажат в узкую полосу при наличии свободного места
- **PASS**: ширина используется разумно

### M3. Visual Hierarchy
Должна читаться иерархия: заголовок → подзаголовок → контент.
- **WARN**: все элементы одного размера / веса — непонятно что главное
- **WARN**: заголовок не выделяется относительно контента
- **PASS**: иерархия очевидна с первого взгляда

### M4. Glance Test (3 seconds)
За 3 секунды должна быть понятна главная мысль слайда.
- **WARN**: слайд перегружен — более 6 буллетов или более 50 слов в body
- **WARN**: нет явного фокуса — всё одинаково важно
- **PASS**: главная мысль читается сразу

---

## Рекомендательные проверки (Minor — WARN без блокировки)

### R1. Template Integration
Контент органично сочетается с дизайном шаблона.
- **WARN**: элементы визуально конфликтуют с фоном шаблона
- **PASS**: контент выглядит как часть единого дизайна

### R2. Color Consistency
Используются цвета из палитры шаблона: NAVY `#282B4D`, ORANGE `#FF7000`, SKY `#5B9BD5`, WHITE.
- **WARN**: появляются случайные/неуместные цвета
- **PASS**: палитра консистентна

### R3. Spacing Rhythm
Отступы между элементами равномерны и пропорциональны.
- **WARN**: элементы слипаются или расставлены хаотично
- **PASS**: ритм отступов очевиден

---

## Формат оценки

Для каждого слайда:

```json
{
  "slide": 2,
  "name": "Bio",
  "overall": "FAIL|WARN|PASS",
  "checks": {
    "C1_safe_zone":        {"status": "FAIL", "detail": "Bullet list starts at x≈0.5\", overlapping wave"},
    "C2_text_readability": {"status": "PASS", "detail": ""},
    "C3_content_visible":  {"status": "PASS", "detail": ""},
    "M1_vertical_balance": {"status": "WARN", "detail": "Bottom 50% empty"},
    "M2_horizontal_space": {"status": "PASS", "detail": ""},
    "M3_visual_hierarchy": {"status": "PASS", "detail": ""},
    "M4_glance_test":      {"status": "PASS", "detail": ""},
    "R1_template_integration": {"status": "PASS", "detail": ""},
    "R2_color_consistency":    {"status": "PASS", "detail": ""},
    "R3_spacing_rhythm":       {"status": "PASS", "detail": ""}
  },
  "fix_instructions": [
    "Move bullet_list left from 0.5 to 3.92",
    "Spread bullets vertically to fill top=2.0 to top=6.5"
  ]
}
```

**overall** = FAIL если хотя бы один C* = FAIL
**overall** = WARN если нет FAIL, но есть M* или R* = WARN
**overall** = PASS если все проверки PASS

---

## Критерии приёмки

Слайд принимается в финальную презентацию только при:
- `overall == PASS` ИЛИ
- `overall == WARN` с незначительными R* предупреждениями (на усмотрение)

Слайды с `overall == FAIL` должны быть исправлены и перепроверены.

## Специфика шаблонов

### Общие правила для всех шаблонов
- **Декоративные элементы** (волны, полосы, треугольники, кавычки) — НЕ ДОЛЖНЫ перекрывать контент
- **Safe zone** зависит от конкретного шаблона и layout. Определяется по placeholder boundaries из audit данных
- **Масштаб**: шаблоны 10"×5.625" используют scale 0.75 — координаты из design-system.json автоматически масштабируются через S()/SH()
- **Layout index**: ВСЕГДА брать из `template-library.md`. Никогда не угадывать. При несовпадении — перезапустить `audit-template.py`

### Modern Business (13.33"×7.5", нативный PPT)
- Декоративная волна: `x = 0 → 4.25"`, полная высота
- Безопасная зона: `left ≥ 3.92"` (по TITLE placeholder)
- Cover layout (0): `left ≥ 4.42"` (по Cover TITLE placeholder)
- Пустой layout (8): `left ≥ 4.25"` (волна из slide master)
- Футер: `top ≥ 6.95"` — зона нижних placeholder, не трогать

### Salerio (10"×5.625", Google export)
- Декоративные skew-фигуры в углах — не перекрывают контентную область
- Заголовок в синей полосе вверху — placeholder обрезает по ширине
- Safe zone: определяется TITLE + BODY placeholder boundaries

### Mercutio (10"×5.625", Google export)
- Цветной фон на контентных layouts — текст должен быть белым/светлым
- Декоративная вертикальная полоса слева — узкая, не мешает
- Дублированные layouts (0-10 и 11-16) — разные цветовые схемы

### Antonio (10"×5.625", Google export)
- Светлый фон, серый заголовок — проверить контраст (может быть < 4.5:1)
- Кавычки-декор могут перекрывать текст на некоторых layouts
- Цветные полосы внизу — не мешают контенту

### Hendrix (13.33"×7.5", Google export)
- 20 layouts, сложная структура — использовать только проверенные
- Фоновые декоративные фигуры помечены SmartArt — ложноположительный результат
- Safe zone: TBD, проверять визуально для каждого используемого layout

### Technology Pixels (10"×5.625", Google export)
- Layout 2 (TITLE_1_1) содержит SmartArt — НЕ использовать
- Тёмный фон — текст должен быть светлым

```
generate-pptx-vN.py
       ↓
verify-slides.py  (win32com → PNG)
       ↓
Claude reads PNGs → оценивает по критериям выше
       ↓
      PASS? ──► DONE
       |
      FAIL/WARN
       ↓
Claude исправляет generate-pptx-vN.py
       ↓
    (повтор)
```
